# Simple ToDo App

Simple ToDo app bat Android Studio-n Kotlin erabiliz sortua. Erabiltzaileak zerrenda batean zereginak gehitu, ikusi eta ezabatu ditzake.

## Ezaugarriak

- Zeregin berriak gehitu
- Zereginak zerrendan ikusi
- Zereginak ezabatu
